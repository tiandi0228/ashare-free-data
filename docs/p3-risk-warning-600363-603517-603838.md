## CNINFO index date check

Queried the CNINFO historical index (`POST /new/hisAnnouncement/query`, by issuer and bounded date window) and matched `secCode`, `announcementId`, and `adjunctUrl` to each original. Re-run the offline validator with `python -m collector.p3_risk_warning_index_dates evidence/p3_risk_warning_index_dates.json`. The three raw `announcementTime` values decode to midnight in UTC+8 on 2026-09-29, 2026-10-19, and 2026-10-17 respectively. The saved JSON is a projection of the observed index rows, not independent evidence of actual availability. No precision beyond the index date is accepted, even if the index field carries a non-midnight clock time.
